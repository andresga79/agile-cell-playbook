# Lean Canvas e hipótesis

**Fase:** 1 y 6 · **Origen:** Lean Startup (Ash Maurya, Eric Ries)

## Lean Canvas

| Bloque | Contenido |
|---|---|
| 1. Problema | Los 3 problemas principales del usuario |
| 2. Segmento de clientes | Quién tiene el problema; *early adopters* |
| 3. Propuesta de valor única | Por qué somos diferentes y vale la pena |
| 4. Solución | Las 3 capacidades principales |
| 5. Canales | Cómo llegamos al usuario |
| 6. Fuentes de ingreso / ahorro | Cómo genera valor económico |
| 7. Estructura de costos | Qué cuesta construir y operar |
| 8. Métricas clave | Las que indican progreso real (aquí vive el MVO) |
| 9. Ventaja injusta | Lo que no se puede copiar fácilmente |

Completar en el orden numérico. Para productos internos, "ingreso" se reemplaza por ahorro, reducción de riesgo o productividad.

## Tarjeta de hipótesis

```
ID:            H-001
Creemos que:   [entregable o cambio]
Para:          [actor / segmento]
Logrará:       [impacto en el comportamiento]
Lo sabremos:   [métrica] pase de [línea base] a [umbral] en [plazo]
Riesgo:        Alto / Medio / Bajo
Valor:         Alto / Medio / Bajo
Experimento:   [tipo: entrevista, prototipo, fake door, A/B, concierge, MVP]
Costo:         [días-persona]
Resultado:     Validada / Invalidada / No concluyente
Decisión:      Perseverar / Pivotar / Parar
Aprendizaje:   [qué aprendimos]
```
