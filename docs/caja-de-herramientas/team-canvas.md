# Team Canvas

**Fase:** 0 · **Duración:** 1,5 a 2 horas · **Participantes:** toda la célula, incluido el PO.

## Bloques

| Bloque | Pregunta | Respuesta del equipo |
|---|---|---|
| Personas y roles | ¿Quiénes somos y qué rol cumple cada uno? | |
| Propósito | ¿Por qué existe este equipo? ¿Qué valor aporta al negocio? | |
| Metas | ¿Qué queremos lograr en los próximos 3–6 meses? | |
| Valores | ¿Qué principios guían nuestras decisiones? | |
| Reglas y actividades | ¿Cómo trabajamos? Horarios, canales, acuerdos | |
| Necesidades y expectativas | ¿Qué necesita cada persona para dar lo mejor? | |
| Fortalezas y activos | ¿Qué habilidades y recursos tenemos? | |
| Debilidades y riesgos | ¿Qué nos puede frenar? | |

## Facilitación

1. Empezar por **personas y roles**, terminar por **reglas** (las reglas surgen de lo anterior).
2. Escritura individual en silencio (3 min por bloque), luego compartir y agrupar.
3. Publicar el resultado en el espacio del equipo y revisarlo cada trimestre o cuando cambie la composición.
