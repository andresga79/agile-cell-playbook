# Kanban Maturity Model

**En una frase:** El Kanban Maturity Model (KMM) es un mapa de siete niveles de madurez organizacional que relaciona prácticas de Kanban, cultura y resultados de negocio, para elegir el siguiente paso de mejora.

**Área:** Kanban · **Lectura:** ~3 min

## Qué es

David J. Anderson y Teodora Bozheva publicaron el KMM en 2018 (la segunda edición es de 2020). Cruza las seis prácticas generales del Kanban Method con siete niveles, del 0 al 6. En cada nivel describe qué prácticas aparecen, con qué profundidad, qué valores culturales las sostienen y qué resultados se pueden esperar.

| Nivel | Nombre | Rasgo principal |
|---|---|---|
| 0 | *Oblivious* | No hay conciencia de que el trabajo sigue un proceso |
| 1 | *Team-focused* | Tableros por equipo o por persona, primeras políticas |
| 2 | *Customer-driven* | Un flujo definido de punta a punta, foco en el cliente |
| 3 | *Fit-for-purpose* | El servicio cumple lo que el cliente espera y se mide |
| 4 | *Risk-hedged* | Decisiones con modelos y datos, riesgos cubiertos |
| 5 | *Market leader* | Se optimiza el servicio para todas las partes interesadas |
| 6 | *Built for survival* | La organización se reinventa ante cambios del entorno |

Los niveles describen a la organización o a un servicio, no a las personas. Un mismo lugar puede tener equipos en niveles distintos.

## Para qué sirve (y cuándo no)

Sirve para elegir el siguiente paso con criterio. Si un equipo está en el nivel 1, pedirle pronósticos probabilísticos o revisiones de riesgo es saltarse escalones. El modelo también ayuda a explicar a la dirección por qué ciertos resultados (como la previsibilidad) exigen antes otras prácticas.

No sirve como nota para comparar equipos, como certificación ni como meta en sí misma ("llegar al nivel 3 este año"). Usado así, genera prácticas de fachada. Para un equipo que recién empieza, basta con saber que existe y mirar el escalón siguiente.

## Cómo se aplica

1. Observa el sistema real (tablero, reuniones y datos), no lo que dice el proceso escrito.
2. Ubica el nivel más alto en que las prácticas se sostienen sin esfuerzo. Lo que aparece solo a veces todavía no es ese nivel.
3. Elige una o dos prácticas del nivel siguiente como experimento.
4. Revisa en uno o dos meses si se sostienen.

El [assessment de madurez](../../caja-de-herramientas/assessment-madurez.md) del playbook mide otras dimensiones, más allá de Kanban. Úsalo como base y el KMM como lupa para la dimensión de flujo.

## Errores típicos

- Usarlo como auditoría y presentar el resultado como ranking.
- Declarar un nivel porque existe la práctica en papel.
- Querer subir varios niveles a la vez.
- Ignorar la cultura: copiar las prácticas sin los valores que las sostienen.

## Qué observar al llegar a un equipo

- ¿Hay tableros personales, uno por equipo o uno que cruza equipos de punta a punta?
- ¿El tablero muestra el trabajo desde el pedido del cliente hasta la entrega, o solo una parte?
- ¿El equipo sabe qué espera su cliente y mide si lo cumple?
- ¿Se usan datos para pronosticar y para decidir, o solo para reportar?
- ¿Las mejoras recientes vinieron del equipo o se impusieron desde fuera?
