# Ruta de estudio

Diez sesiones de unos 25 minutos, pensadas para leer en el teléfono. Siguen un orden: primero Scrum, luego Kanban, después las métricas de flujo y por último Scrumban, para que cada tema se apoye en el anterior. La última sesión junta todo para preparar la llegada a un equipo.

Cada sesión incluye lecturas, una pregunta para autoevaluarte y un ejercicio corto. El detalle de cada sesión se agrega a medida que se publica su área.

| Sesión | Tema |
|---|---|
| 1 | Scrum: fundamentos y accountabilities |
| 2 | Scrum: Sprint y sus eventos |
| 3 | Scrum: artefactos, refinamiento y antipatrones |
| 4 | Kanban: visualizar el trabajo |
| 5 | Kanban: WIP, pull y políticas explícitas |
| 6 | Kanban: clases de servicio y cadencias |
| 7 | Métricas de flujo: vocabulario y Ley de Little |
| 8 | Métricas de flujo: CFD, scatterplot y pronóstico |
| 9 | Scrumban |
| 10 | Preparar la llegada a un equipo |
