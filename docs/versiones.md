# Versiones

La guía publicada en la raíz del sitio es siempre la **última versión**. Cada versión anterior queda archivada tal como se publicó, para que una célula que adoptó una versión pueda seguir consultándola. El detalle de cada cambio está en el [changelog](changelog.md).

!!! note "Cómo se generan"
    Cada tag `vX.Y.Z` del repositorio se construye automáticamente en `versiones/vX.Y.Z/` en cada publicación. Las versiones archivadas muestran un aviso con enlace a la versión actual y no se corrigen.
