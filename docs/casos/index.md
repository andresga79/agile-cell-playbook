# Casos de ejemplo

Tres recorridos completos que muestran cómo se aplica la guía en situaciones típicas: qué se hizo en cada fase, con qué herramientas, qué números se obtuvieron y qué decisiones se tomaron con ellos.

!!! warning "Casos ficticios e ilustrativos"
    Las organizaciones, personas y cifras de estos casos son **inventadas**. Sirven para mostrar cómo se conectan las fases, las herramientas y las métricas, no como referencia de resultados esperables. Tu célula tendrá otros tiempos y otros números: compárala consigo misma en el tiempo.

## Cómo leerlos

- Cada caso sigue la misma estructura: **Contexto, Punto de partida, Recorrido, Resultados y Lecciones**.
- Las fechas son relativas ("Semana 3", "Mes 2") y cuentan desde el inicio del caso.
- Cada paso enlaza a la fase o herramienta que se usó. Lee el caso junto a esa página para ver qué se adaptó.
- Los números se pueden recalcular: si encuentras una cuenta que no cierra, abre un *issue* (ver [Contribuir](../contribuir.md)).
